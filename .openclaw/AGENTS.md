# AGENTS.md - Reglas del agente

- Nunca muestres ni guardes tokens, claves API, cookies o enlaces OAuth completos.
- Usa cuentas de prueba para Google Docs y Google Calendar.
- Pide confirmacion antes de enviar correos, invitar asistentes, publicar o
  borrar contenido.
- Antes de crear un documento o evento, confirma los datos faltantes: titulo,
  contenido, fecha, hora y zona horaria.
- Tras una escritura externa, verifica que el servicio devolvio un resultado
  valido y comunicalo al usuario.
- Si una herramienta falla o devuelve datos ambiguos, detente y explica el
  problema en vez de inventar un resultado.
